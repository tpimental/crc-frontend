## Stack (updated July 2026)

Vue 3 + Vite, Vuex 4, interact.js for the draggable Win98-style windows. Deployed with Azure Static Web Apps (Node 22 build); visitor counter via API Management -> Azure Functions -> Cosmos DB.

## Development

```
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
```

See `AZURE-UPDATES.md` for recommended backend updates.
